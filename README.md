# AdventurerCity

Градостроитель + гильдия героев + данжи на Unity. Геймдизайн-документ: https://claude.ai/code/artifact/73a9a713-0c4e-4ef3-b936-88add570da04

Сейчас реализован этап 1 роадмапа — скелет города: дороги, установка зданий, тик симуляции, 4 ресурса + золото, 6 зданий, жители с домом, работой и нуждами, сохранение. Графика — кубики.

## Открыть проект

1. Редактор: Unity 6000.6.6f1 (см. `ProjectSettings/ProjectVersion.txt`).
2. Unity Hub → Add → Add project from disk → выбрать эту папку, или `unity open <путь к проекту>` через Unity CLI. Пакет `com.unity.pipeline` нужен, чтобы управлять открытым редактором из Unity CLI (`unity status`, `unity command ...`).
3. Открыть любую сцену (подойдёт пустая) и нажать Play: `GameRunner` создаёт камеру, свет и город сам через `RuntimeInitializeOnLoadMethod`.

Если при Play сыпятся ошибки `InvalidOperationException` про Input — в Project Settings → Player → Active Input Handling выбрать «Input Manager (Old)» или «Both».

## Управление

- ЛКМ — строить / выбрать здание, ПКМ или Esc — отмена, R — поворот.
- Дорога — зажать ЛКМ и тянуть (Г-образная линия).
- WASD/стрелки — движение камеры, Q/E — поворот, колесо — зум, СКМ — панорама.
- Tab или кнопка «Экономика» — панель ресурсов: запас, приход/расход в день, на сколько дней хватит, кто производит и кто потребляет, лимиты запаса (производство останавливается, когда на складе лимит; по умолчанию лимит только у досок — 80).
- В карточке производственного здания — его выработка в день и кнопка «Пауза». В журнале — предупреждение, когда ресурса осталось меньше чем на 3 дня.
- Гильдия (фиолетовое здание): клик по ней открывает карточку — найм героя (50 золота + 10 досок, берёт взрослого жителя, лучше безработного), список героев, галочки для отряда до 3 человек и отправка в «Заброшенную шахту» (2 хлеба на героя). Отрядов в походе может быть сколько угодно; ограничение экономическое: каждый герой ежедневно берёт 1 хлеб пайка и 3 золота, голодный герой в поход не идёт. Пока отряды в походе, внизу слева панель с комнатой, полосками здоровья и журналом боя. Добыча — руда и золото; руда нужна для «Добротного дома» (5 шт.). Герои получают опыт (250 × уровень за уровень), ранения (−10% здоровья на 3 дня) и могут погибнуть.
- F5 / F9 — сохранить / загрузить. Автосейв раз в игровой день и при выходе: `Application.persistentDataPath/city.json`.

## Структура

- `Assets/Game.Simulation` — чистый C# без `UnityEngine` (`noEngineReferences`): `World` (тик, логистика, распределение рабочих, производство), `Citizens` (житель — структура в списке: имя, возраст, дом, работа; распорядок дня), `Households` (нужды домов, переселенцы, рождения, рост и упадок), `Commands` (всё, что меняет мир), `ContentLibrary` (данные зданий и уровней домов), `WorldState` (сохраняемое состояние).
- `Assets/Game.Simulation/Combat` — бой и данж (этап 2, пока без UI): `CombatData` (классы, враги, константы баланса), `Combatant`, `Battle` (тик 0,1 с, ИИ ролей, угроза, прерывания, «при смерти»), `Expedition` (комнаты шахты, отдых, отступление, добыча). Числа подобраны прогонами по 1 000 вылазок — результаты в геймдиз-документе, раздел «Первый данж».
- `Assets/Game.View` — Unity-слой: `GameRunner` (запуск, тик, сохранения), `CameraRig`, `CityRenderer`, `BuildTool`, `Hud` (IMGUI), `SaveSystem`.

Правила:

- View не меняет состояние напрямую — только через `World.Enqueue(command)`.
- Всё, что должно сохраняться, — публичные поля в `WorldState`/`Building`/`Citizen`; вычисляемое на лету помечено `[NonSerialized]`. При несовместимом изменении формата — поднять `WorldState.CurrentFormat`, старые сохранения тогда игнорируются.
- Жители — простые агенты (без черт и хроники); глубокие личности — только у героев. Ходьбы пока нет: распорядок (`World.ActivityOf`) считается, но не отрисовывается. Толпу планируется делать через Burst + GPU-инстансинг, без Entities.
- Симуляция компилируется под C# 9 / .NET Standard 2.1 (ограничения Unity 6): без file-scoped namespace, records с `init`, collection expressions.

## Ключевые числа (заглушки для баланса)

- 1 тик = 1 секунда на x1, игровой день = 30 тиков.
- Склад обслуживает 12 клеток дороги; дальше −5% за клетку, минимум 50%. Без дороги к складу здание не работает.
- Жилец съедает 1 еду в день (зерно, а если его нет — хлеб; «Добротный дом» — только хлеб). Хлеб нужен «Добротным домам», пайку героев и провизии. Дома 2+ уровня жгут 1 бревно в день.
- Дом растёт после 3 сытых дней подряд при полном заселении и запасе досок; приходит в упадок после 3 голодных дней, лишние жильцы уходят из города.
- В сытый подключённый дом со свободным местом раз в день приходит переселенец 18–40 лет; если в доме двое взрослых — с шансом 10% вместо этого рождается ребёнок.
- Игровой год = 30 дней (15 минут на x1), взрослым житель становится в 16 лет. Работу получают только взрослые, по порядку постройки зданий.

Константы — `SimConstants.cs`, здания и рецепты — `Content.cs`.
